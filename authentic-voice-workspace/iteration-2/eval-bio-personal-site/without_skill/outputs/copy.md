# Hi. I write code.

Slowly, on purpose, and with a lot of help from the internet.

I've been at it seriously since 2022. "Seriously" mostly means I've filled a hard drive with half-finished side projects and formed strong opinions about type systems I don't fully understand.

Right now that's Rust and Elixir. I'm still, honestly, pretty bad at both. I've decided that's part of the hobby.

## About

This is a homepage, not a resume, so we're skipping achievements. I write code after work, in the hours most people use for hobbies like "rest" or "a social life."

Things I've made, loosely:

- **Pasta Timer CLI** — a command-line timer that tells you when your pasta is done. It works by accident more often than not. I tell myself that's just "robust under unpredictable conditions."
- **A Discord server** — where people argue about Linux distros at 3am. I run it, which mostly means I keep the lights on and let them sort it out.
- **A blog** — I update it every few months, usually all in one night, then forget it exists for a while.

The bar for "working" is low and I've learned to celebrate small wins: a program that compiles on the first try, a crash that finally makes sense, a 3am argument that ends in "okay, fair."

If any of that sounds like your thing, you're welcome. Bring pasta.
